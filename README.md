# PHẦN CÁ NHÂN – HỌC BỔNG & CỘNG ĐỒNG OXFORD NHÀ BÈ

Đây là module riêng của thành viên phụ trách **Học bổng + Cộng đồng** trong website trường.

## 1. Học bổng
- Tìm kiếm và lọc học bổng
- Chọn chương trình
- Chọn kiểu hồ sơ
- Nhập thông tin
- Tải minh chứng
- Lưu hồ sơ nháp
- Gửi hồ sơ
- Sinh mã hồ sơ
- Theo dõi hồ sơ trên thiết bị

## 2. Cộng đồng
- Danh sách bài viết
- Tìm kiếm
- Lọc theo chủ đề
- Đăng bài
- Like
- Bình luận
- Lưu dữ liệu bằng localStorage

## Tệp phụ trách
- pages/hocbong.html
- css/hocbong.css
- js/hocbong.js
- pages/cong-dong.html
- css/cong-dong.css
- js/cong-dong.js
- data/community.json

## Đưa vào GitHub nhóm

`feature/hocbong-congdong`

`feat: add scholarship and community modules`
